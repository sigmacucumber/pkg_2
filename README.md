Чтение информации из графических файлов

Описание
приложение на Python для анализа метаданных графических файлов. 
Программа считывает и отображает основную информацию об изображениях: 
размер, разрешение, глубину цвета, тип сжатия и размер файла.

Поддерживаемые форматы
- JPG/JPEG
- GIF
- TIFF/TIF
- BMP
- PNG
- PCX

Возможности
- Сканирование папок (рекурсивно) и выбор отдельных файлов
- Фильтрация по форматам файлов
- Отображение результатов в таблице
- Экспорт данных в CSV
- Многопоточная обработка (интерфейс не зависает)
- Прогресс-бар при сканировании

Технологии
- Python 3.9
- PyQt5 (интерфейс)
- Pillow (чтение метаданных изображений)
- Qt Designer (проектирование UI)

Структура проекта
- pkg_2.py              Основной файл приложения
- mainwindow_ui.py      Сгенерированный из ui код интерфейса
