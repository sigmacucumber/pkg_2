Чтение информации из графических файлов
Описание
Десктопное приложение на Python для анализа метаданных графических файлов. Программа считывает и отображает основную информацию об изображениях путём прямого парсинга бинарных заголовков файлов согласно спецификациям форматов: размер, разрешение (DPI), глубину цвета, тип сжатия, размер файла и дополнительную техническую информацию.

Поддерживаемые форматы
JPG/JPEG — парсинг маркеров SOF0/SOF2, таблиц квантования (DQT), APP0 (JFIF) для DPI
GIF — чтение заголовка GIF87a/GIF89a, глобальной таблицы цветов (GCT)
TIFF/TIF — парсинг IFD-тегов (Little/Big Endian), включая X/Y Resolution
BMP — чтение BITMAPINFOHEADER, конвертация пикселей/метр → DPI
PNG — парсинг чанков IHDR и pHYs
PCX — чтение 128-байтного заголовка, определение палитры

Возможности
Сканирование папок (рекурсивно) и выбор отдельных файлов
Фильтрация по форматам через чекбоксы
Отображение результатов в таблице (8 колонок)
Экспорт данных в CSV
Многопоточная обработка (ThreadPoolExecutor, 8 потоков) — интерфейс не зависает
Прогресс-бар и статусная строка при сканировании
Обработка больших коллекций (тестировалось на 600+ файлах ~2 ГБ)

Технологии
Python 3.9 — язык программирования
PyQt5 — графический интерфейс (QMainWindow, QTableWidget, QThread)
struct — бинарный парсинг заголовков файлов
ThreadPoolExecutor — многопоточность для быстродействия
Qt Designer — проектирование интерфейса
