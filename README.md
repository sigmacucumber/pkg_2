Чтение информации из графических файлов

Описание

Десктопное приложение на Python для анализа метаданных графических файлов. Программа считывает и отображает основную информацию об изображениях путём **прямого побайтового парсинга бинарных заголовков** согласно спецификациям форматов: размер, разрешение (DPI), глубину цвета, тип сжатия, размер файла. Дополнительно реализована **детекция битых файлов** с классификацией ошибок по стадиям и **распознавание файлов, не являющихся изображениями** (PDF, DOCX, архивы и др.).

Поддерживаемые форматы

JPG/JPEG — сканирование маркеров 0xFF.., поиск SOF (размеры), APP0/JFIF (DPI), проверка наличия EOI (0xFFD9) в конце файла
GIF — чтение заголовка GIF87a/GIF89a, Logical Screen Descriptor, проверка трейлера 0x3B, обход блоков LZW и Extensions
TIFF/TIF — парсинг IFD-тегов (Little/Big Endian), извлечение тегов 256/257/258/259/282/283/296 (размеры, битность, сжатие, DPI)
BMP — чтение BITMAPINFOHEADER и BITMAPCOREHEADER, проверка соответствия размера пиксельных данных, конвертация pelsPerMeter → DPI
PNG — парсинг чанков IHDR/pHYs/IDAT/IEND, **проверка CRC каждого чанка** через `zlib.crc32`
PCX — чтение 128-байтного заголовка, определение битности и количества плоскостей

Возможности

Сканирование папок (рекурсивно через `os.scandir`) и выбор отдельных файлов
Фильтрация по форматам через чекбоксы
Отображение результатов в таблице (7 колонок)
Подсветка битых/некорректных файлов красным цветом
Экспорт данных в CSV
Многопоточная обработка через QThread
Прогресс-бар и статусная строка при сканировании
Обработка больших коллекций (тестировалось на **6000+ файлов ~2 ГБ**)
Распознавание не-изображений: PDF, DOCX/XLSX/PPTX (ZIP), DOC/XLS (OLE2), MP3, архивы (RAR/7z/GZIP) и другие форматы по сигнатурам
Классификация ошибок по стадиям: `empty`, `too_short`, `signature`, `IHDR`, `SOF`, `IEND`, `truncated`, `corrupted` и т.д.
Масштабируемый интерфейс — растягивается при изменении размера окна
